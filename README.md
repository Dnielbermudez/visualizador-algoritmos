# Visualizador de algoritmos de ordenamiento y búsqueda (Java)

Visualizador interactivo, en estilo pixel, para estudiar paso a paso algoritmos de ordenamiento y búsqueda de la materia Análisis de Algoritmos.

## Algoritmos

| Grupo | Algoritmos |
|---|---|
| Simples | Intercambio, Burbuja, Selección, Inserción |
| Avanzados | Shell Sort, QuickSort, MergeSort, HeapSort, Radix Sort, Counting Sort, Tim Sort (simplificado), Intro Sort |
| Búsqueda | Binaria iterativa, Binaria recursiva, Interpolación |

## Qué incluye

- Animación paso a paso, con el código Java y la línea en ejecución resaltada.
- Variables en vivo, pila de llamadas para los algoritmos recursivos e historial de pasos.
- Panel para comparar todos los algoritmos sobre el mismo arreglo: aleatorio, casi ordenado, al revés o ya ordenado.
- Guía de cada algoritmo: qué hace, cómo lo hace, para qué sirve, complejidad y mejor uso.
- Arreglo propio y valor a buscar personalizados.

## Uso

Es un solo archivo `index.html`, sin dependencias. Ábrelo en el navegador o publícalo con GitHub Pages.

### Atajos de teclado

| Tecla | Acción |
|---|---|
| Espacio | Iniciar o pausar |
| ← → | Paso anterior o siguiente |
| 1 a 8 | Cambiar de algoritmo dentro del grupo |
| N | Nuevo arreglo |
| R | Reiniciar |
